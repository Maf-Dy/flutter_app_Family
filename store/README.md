# Google Play store assets

All images here are generated by `node store/tool/make_assets.mjs` (run from the repo root; needs Playwright with Chromium). The same script redraws the app launcher icons.

| File | Play Console field | Spec |
| --- | --- | --- |
| `play_icon_512.png` | App icon | 512 x 512, 32-bit PNG |
| `feature_graphic_1024x500.png` | Feature graphic | 1024 x 500, 24-bit PNG, no alpha |
| `screenshot_frame_template_1080x1920.png` | (template) | 1080 x 1920, transparent screen area at x 90, y 330, 900 x 1600 |
| `screenshots/phone_N.png` | Phone screenshots | 1080 x 1920 (9:16), 2 to 8 needed |

## Phone screenshots

1. Take screenshots on a phone (any portrait size; they are cropped from the top to fit 9:16).
2. Put them in `store/screenshots/raw/`, named in the order you want (`1.png`, `2.png`, ...).
3. Run `node store/tool/make_assets.mjs`. Each one is framed with a caption in English and Arabic; edit `frameCaptions` in the script to change the captions.
